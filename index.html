Aaron's assistant

A private, personal assistant. Not a public service.

Aaron's assistant is a personal AI assistant used by one person, its owner. It runs on the owner's own server and talks only to the owner.

With the owner's permission it can read the owner's Gmail and Google Calendar so it can answer questions like "anything urgent in my email?" or "what's on tomorrow?". It cannot send, delete or change email or calendar events - it only ever asks Google for read-only access.

It is not offered to anyone else, and there is nothing to sign up for.
