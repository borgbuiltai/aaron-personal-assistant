Privacy policy

Last updated 29 September 2026

Aaron's assistant is a private assistant used only by its owner. This page explains what it does with Google data.

What it reads

  • Gmail - read-only (gmail.readonly): searching and reading the owner's emails when the owner asks.
  • Google Calendar - read-only (calendar.events.readonly): listing the owner's events.

It never asks for permission to send, delete or change anything.

How it is used

Only to answer the owner's own requests - for example summarising new email or listing tomorrow's meetings. To do that, the relevant text is sent to Anthropic's Claude AI service for processing, under Anthropic's commercial terms. It is not used for advertising, not sold, and not shared with anyone else.

Where it is kept

The assistant runs on the owner's own private server (Amazon Web Services, Sydney, Australia). Emails are fetched when needed, not copied in bulk. Conversations with the assistant, which may include parts of emails, are kept on that server so the assistant can remember context, and are backed up privately within the same account.

Google API Services User Data Policy

Aaron's assistant's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Turning it off

Access can be removed at any time at myaccount.google.com/permissions. After that the assistant can no longer read anything.

Contact

Questions go to the support email shown on Google's sign-in screen for this app.
